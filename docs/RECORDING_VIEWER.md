# CBRAIN Recording Viewer 2.1.0

저장한 CBRAIN HDF5 파형을 확인하는 macOS 앱입니다. `app/CBRAIN Recording Viewer.app`을
열고 **파일 열기**를 누르세요. USB 동글이나 헤드스테이지가 필요하지 않습니다.

## 파일 열기와 전환

- **파일 열기**: `.h5` 또는 `.hdf5`를 한 개 또는 여러 개 선택합니다.
- **세션 폴더 열기**: 해당 폴더 바로 아래의 HDF5 파일을 목록에 넣습니다.
- 파일/세션 폴더를 창으로 끌어 놓거나 Finder의 **다음으로 열기 → CBRAIN Recording Viewer**를 사용할 수 있습니다.
- 여러 파일을 열면 위쪽 목록에서 볼 파일을 선택합니다. 한 번에 한 파일의 채널을 표시합니다.
- **파일 정보**에는 전체 경로, 채널 순서, 환산값, 누락 구간 수와 저장 속성이 나옵니다.

파일 상단에 기기·동글 이름, 샘플레이트, 채널 수, 기록 길이와 누락 샘플 수를 표시합니다.
센서 출처나 전압 환산 정보가 없는 구형 파일은 그 사실을 함께 표시합니다.

## 파형 보기

**CH 버튼**을 누르면 채널을 표시하거나 숨깁니다. 번호는 파일에 저장된 실제 채널 순서입니다.
**모두 표시**로 전체 채널을 다시 켭니다. 채널이 많으면 파형 영역을 세로로 스크롤합니다.

**이전/다음 구간**이나 슬라이더로 이동하고, **시작**에 초를 입력해 원하는 위치로 이동합니다.
**표시 구간**은 0.1초부터 300초까지 또는 **전체**를 선택합니다. **확대 + / 축소 −**는
표시하는 시간 길이를 변경합니다. **진폭**은 채널별 자동 범위 또는 고정 ±값입니다.
표시 단위는 각 채널 왼쪽에 표시됩니다. 마우스를 파형 위에 올리면 해당 위치의 시간이 나옵니다.

시간축의 0초는 첫 저장 샘플이며, 이후 시간은 샘플 카운터와 샘플레이트로 계산합니다.
누락된 시간은 그대로 남기고 샘플 사이의 누락 구간을 선으로 잇지 않습니다. 확대 전에는
가로 픽셀에 해당하는 각 시간 구간의 최소·최대를 그려 짧은 피크를 보존합니다. 충분히
확대하면 개별 샘플을 표시합니다. 표시용 필터나 임의 기준선 보정은 적용하지 않습니다.

LED 상태를 기록한 파일에는 LED 1·2 표시가 함께 나옵니다. 축소 화면은 각 시간 구간에
한 번이라도 ON이 기록되면 표시하므로, 정확한 켜짐 길이는 확대해서 확인하세요.
여러 파일의 시간축을 공통 시계로 동기화하거나 동시에 겹쳐 그리는 기능은 포함하지 않습니다.

## 이미지 저장과 종료

**파형 PNG 저장**은 현재 시간 구간의 선택 채널을 이미지로 저장합니다. 세로 스크롤 아래의
선택 채널도 이미지에 포함합니다. **종료** 또는 창 닫기로 앱을 닫습니다.
단축키: `⌘O` 파일 열기, `PageUp/PageDown` 이전·다음 구간.

Viewer는 HDF5를 읽기 전용으로 엽니다. 다른 앱의 동글 연결이나 저장 설정을 변경하지
않습니다. 열어 둔 원본 파일이 변경되면 다시 열도록 안내합니다. 녹화 중인 파일 대신
Studio에서 녹화 정지를 마친 파일을 여세요. 파형은 파일에 저장된 신호이며, 구형 파일을
열었다는 것만으로 센서 출처를 새로 검증하는 것은 아닙니다.

## 개발·검증

```bash
.venv/bin/python tools/recording_viewer.py /path/to/Device_002.h5
.venv/bin/python tools/build_suite.py Viewer
QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest \
  tests/test_saved_recording.py tests/test_recording_viewer.py -q -p no:cacheprovider
```

뷰어 테스트 24개: 전압 환산, 높은 카운터의 시간 정밀도, 축소 시 피크·LED 보존,
누락 시간, 빈 기록, 1–16채널, 구형 데이터 인코딩, 잘못된 파일, 읽기 취소·파일 변경,
GUI 시간/채널 조작·파일 전환·PNG 저장과 읽는 중 종료를 검증했습니다.
실제 저장 파일 3개(약 49초, 15.8분, 29.8분)를 읽고 원본 SHA-256 불변을 확인했습니다.
검증 상세는 `build/viewer-real-file-validation.json`에 있습니다.
