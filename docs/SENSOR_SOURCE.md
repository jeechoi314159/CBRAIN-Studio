# 센서 신호 확인 — 앱 2.0.5 / 헤드스테이지 0.3.0

## 이번 톱니파의 원인

0.2.x 헤드스테이지 코드는 부팅 때 RHD2216 초기화가 실패하면 `synth_sample()`로
시험 신호를 생성했습니다. 출력 행 c의 샘플 n은 `(((n*(7+3*c)) & 1023)-512)*16`입니다.
1024 Hz, 4채널에서 7/10/13/16 Hz의 톱니파가 생기며, 구형 앱의 환산에서는 약 ±1250 µV로
나타납니다. 사용자가 보낸 화면과 일치합니다. USB·무선 전송이 성공해도 센서 측정을 뜻하지
않는데, 앱 2.0.4까지는 이를 '수신 중'으로 표시하고 녹화를 허용했습니다.

실제 보드의 초기화 실패 원인은 아직 실물 진단으로 확인하지 않았습니다. 저장소의 핀맵과
overlay는 MOSI=P0.11, MISO=P0.12, SCLK=P0.13, CS=P0.14로 일치합니다.
소프트웨어 수정만으로 실제 센서가 정상 동작한다고 판정하지 않습니다.

## 사용자가 진행할 순서

1. 실행 중인 CBRAIN 앱을 종료하고 `app/CBRAIN Device Setup.app`을 다시 엽니다.
   상단 **2.1.0**을 확인합니다. 아래 센서 확인 수정은 2.0.5부터 포함됐습니다.
2. 동글 연결을 해제하고 CBC-V3/J-Link에 헤드스테이지 하나를 연결합니다.
3. **기기 번호 · 펌웨어 → J-Link 찾기 → 현재 기기 확인**. 기존 번호는 그대로 둡니다.
4. **펌웨어 설치**에서 새 `app/firmware/headstage_common.hex`를 설치합니다.
   이 파일은 **헤드스테이지용**이며 4채널, 1024 Hz, LED OFF 설정입니다.
   동글의 `dongle_bridge.hex`는 이번 수정에서 바꾸지 않았습니다.
5. **동글 연결 · 확인 → 기기 검색 → 선택 → 연결**.
   정상일 때 **RHD2216 확인 · 수신 중**, 실패하면 **센서 오류**와 원인이 표시됩니다.
6. 오류가 계속되면 표시된 오류 문구를 확인합니다. 전원을 다시 켜도 반복되면 보드의
   3V3 공급, RHD2216 CMOS/LVDS 설정, SPI 네 선과 납땜을 실제 보드에서 점검해야 합니다.
   이는 하드웨어 점검 항목이며 이번 소프트웨어 작업에서 측정하지 않았습니다.

다른 헤드스테이지에도 같은 공통 HEX를 사용할 수 있습니다. 기기 번호는 UICR에 있으며
Device Setup 설치 경로는 번호를 보존·검증합니다. 이전 맞춤 설정/LED 임계값은 새 Builder로
다시 만들어야 합니다. 시험 신호로 계산한 임계값을 재사용하지 마세요.

## 새 동작과 검증 범위

- 앱은 이전 시험 신호의 **정확한 정수 패턴**을 검출하여 표시·저장·보정 전에 차단합니다.
  일반적인 주기 신호를 모양만 보고 시험 신호로 판정하지 않습니다.
- 출처 정보가 없는 구형 펌웨어도 실험 녹화·보정을 허용하지 않습니다.
- 헤드스테이지 0.3.0은 합성 신호 대체 기능을 제거했습니다. 초기화는 50 ms 간격으로
  최대 3회 시도하며 SPI 전송, INTAN ROM, 모델/채널 수, 설정 레지스터를 확인합니다.
  설정 후 보정 전 최소 100 µs를 기다립니다.
- 실패하면 DATA의 `SOURCE_VALID`(bit14), `SENSOR_FAULT`(bit13), 오류 번호(bit4–6)를
  보냅니다. 이때 샘플은 **측정값이 아닌 무효 자리표시자**입니다. 앱은 표시/저장을 차단하고
  펌웨어는 LED 자동 판정에 사용하지 않습니다. 오류는 재시작까지 유지합니다.
- 오류 번호: 1=SPI 버스 준비, 2=SPI 전송, 3=INTAN ROM, 4=RHD2216 모델, 5=설정 검증.
  자세한 ROM 바이트·전송 오류는 RTT 로그에 기록합니다.
- `SOURCE_VALID=1, SENSOR_FAULT=0`은 검증된 RHD2216 소스로 정의합니다. ADC 환산은
  0.195 µV/LSB를 사용하고 HDF5에 출처·환산값을 기록합니다. 변환 도구도 이 값을 읽습니다.
- 출처가 확인되어도 전극 접촉·아날로그 신호 품질·모든 하드웨어 고장을 보장하지 않습니다.
  실제 신호 입력 시험은 별도입니다. 이 작업에서 실물 펌웨어 설치나 장치 수신은 하지 않았습니다.

초기화 절차, ROM, 전압 환산 근거:
[Intan RHD2000 데이터시트](https://intantech.com/files/Intan_RHD2000_series_datasheet.pdf),
pp. 6, 19, 23, 36–37. 실제 C 드라이버의 SPI 파이프라인은 모의 칩으로 시험했습니다.
