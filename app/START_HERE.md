# CBRAIN 2.1.0 — 시작 안내

처음 사용하는 사람은 [하드웨어 준비부터 따라 하는 매뉴얼](../docs/USER_MANUAL_KO.md)을 먼저 읽으세요.
인쇄할 때는 [통합 PDF](../output/pdf/CBRAIN_Manual_KO.pdf)를 사용합니다.

Device Setup·Studio·Firmware Builder의 무선 연결은 **nRF USB 동글만** 사용합니다.
Recording Viewer는 저장 파일을 보는 앱으로 동글이 필요 없습니다. Mac Bluetooth 권한도 필요하지 않습니다.
검색에는 새 `firmware/dongle_bridge.hex`가 설치된 동글이 필요합니다.
실험 녹화에는 **센서 확인 기능이 있는 헤드스테이지 0.3.0**이 필요합니다.
기존 톱니파/구형 펌웨어 사용자는 [센서 확인과 업데이트 순서](../docs/SENSOR_SOURCE.md)를 먼저 따르세요.

네 앱 모두 **오른쪽 아래의 종료 버튼**으로 닫습니다. Studio는 녹화 중이면 종료 여부를
확인하고 저장을 마친 뒤 동글 연결을 해제합니다. 진행 중인 작업이 있으면 작업이 끝날 때까지
종료 버튼이 비활성화됩니다. Viewer를 닫아도 다른 앱의 녹화나 동글 연결에는 영향이 없습니다.

## 처음 준비할 때: CBRAIN Device Setup

1. CBC-V3에 헤드스테이지를 안착시키고 J-Link를 연결합니다.
2. **J-Link 찾기 → 현재 기기 확인**. 기존 ID가 있으면 다시 부여할 필요가 없습니다.
   확인이 끝나면 앱이 헤드스테이지를 재시작하여 무선 광고를 재개합니다.
3. 필요하면 **번호 저장 및 검증**을 누릅니다. ID 외 UICR 설정을 백업·보존합니다.
4. 빈 기기는 공통 녹화 HEX 또는 맞춤 HEX를 선택해 **펌웨어 설치**합니다.
5. **동글 연결 · 확인** 탭 → **기기 검색** → 해당 행의 **선택** 버튼 → 사용할 동글 선택 → **CBRAIN_N 연결**.
   선택한 행은 파란색 **✓ 선택됨**으로 바뀝니다. Device Setup은 한 번에 한 기기씩 준비합니다.
6. 실제 신호가 5초 이상 확인되면 **연결 조합 저장 후 해제**. 그다음 **Studio 열기**.

이미 ID/펌웨어가 준비된 기기는 동글 연결 탭부터 시작할 수 있습니다.
동글 펌웨어 설치는 nRF Connect Programmer에서 DFU 모드로 진행합니다.
Device Setup의 펌웨어 설치 버튼은 헤드스테이지용입니다.

동글은 **CBRAIN_Bridge_1, CBRAIN_Bridge_2, …**로 표시됩니다. 이 Mac에서 처음 찾을 때
번호를 부여하고 USB 일련번호에 연결해 저장하므로, 포트·연결 순서가 바뀌어도 이름이 유지됩니다.
Device Setup·Studio·Firmware Builder가 같은 이름을 사용합니다. 동글 선택 항목에 마우스를
올리면 USB 일련번호와 포트를 확인할 수 있습니다. 이름은 헤드스테이지 번호와 별개이며,
연결 후 파형 제목과 저장 파일에서도 사용한 동글 이름을 확인할 수 있습니다.

## 실험할 때: CBRAIN Studio

1. 사용할 헤드스테이지 전원을 켜고, 기기 수만큼 동글을 연결합니다.
2. **기기 검색** → 발견 목록에서 사용할 기기의 **선택** 버튼을 누릅니다. 여러 기기를 선택할 수 있습니다.
3. 별칭/동물 이름을 입력하고 **CBRAIN_N 연결** 또는 **선택한 N개 연결**을 누릅니다.
   저장된 동글 조합이 있으면 기본 선택에 반영됩니다. 연결 직전 다시 검색해 검증합니다.
4. 수신 상태·파형·누락 수를 확인합니다. 모든 기기가 준비되면 녹화 시작 버튼이 활성화됩니다.
5. 저장 위치와 실험 이름을 정하고 **녹화 시작**.
6. **녹화 정지** 후 파일 검증 결과를 확인하고 **저장 폴더 열기**를 누릅니다.

기기당 HDF5 파일, session.json, integrity.csv가 저장됩니다. 이벤트를 입력하면 events.json도
저장됩니다. 표시 필터/진폭/표시 기기 선택은 원본 저장에 영향을 주지 않습니다.
녹화 정지는 연결을 유지합니다. 실험을 마친 뒤 **연결 해제** 또는 앱 종료를 사용하세요.
신호 수신과 파일 기록은 별도 상태입니다. 오류/누락이 있으면 결과에서 확인해야 합니다.

## 저장 파형을 볼 때: CBRAIN Recording Viewer

1. **CBRAIN Recording Viewer.app**을 엽니다.
2. **파일 열기**로 `.h5`를 선택하거나, **세션 폴더 열기**로 녹화 폴더를 선택합니다.
   파일이나 세션 폴더를 창에 끌어 놓아도 됩니다. 여러 파일은 위쪽 파일 목록에서 전환합니다.
3. **CH 버튼**으로 표시 채널을 고릅니다. **이전/다음 구간**, **시작 시간**, 아래 슬라이더로 이동합니다.
4. **표시 구간 → 전체**로 기록 전체를 보거나 **확대 + / 축소 −**로 자세히 봅니다.
5. **파형 PNG 저장**으로 현재 시간 구간의 선택 채널을 이미지로 저장합니다.

파일에 기록된 환산값을 사용하며 HDF5 원본은 수정하지 않습니다. Studio에서 녹화 정지를
마친 파일을 여세요. 자세한 설명은 [Recording Viewer 사용법](../docs/RECORDING_VIEWER.md)에 있습니다.

## 맞춤 설정이 필요할 때: CBRAIN Firmware Builder

1. 측정 채널·샘플레이트·기기 Notch를 설정합니다.
2. LED를 쓰지 않으면 바로 **펌웨어 생성 및 저장**할 수 있습니다.
3. LED를 쓰면 **기기 연결 · 신호 확인**에서 동글로 기기를 연결합니다.
4. 현재 기기에 설치된 측정 조건과 동일하게 설정한 뒤, 사용할 LED의 채널/대역/배수/색/강도를
   선택하고 **연결 기기로 보정**합니다. 측정 조건을 바꾸려면 먼저 LED OFF 설정을 설치하세요.
5. **펌웨어 생성 및 저장**으로 HEX와 설정 JSON을 만듭니다.
6. 연결을 해제하고 Device Setup에서 HEX를 설치합니다.

## 파일 위치 / 확인 범위

- 기기–동글 조합: `~/Library/Application Support/CBRAIN/devices.json`
- ID 변경 전 UICR 백업: 같은 폴더의 `uicr_backups/`
- 기본 녹화 위치: `~/CBRAIN_recordings/`
- 구형 앱/매뉴얼: `legacy-20260916/` (전환 중 복구용)

이번 버전은 소프트웨어 테스트 및 패키징된 앱의 시작 검증을 통과했습니다.
실물 동글의 검색·다기기 수신, J-Link 쓰기와 장시간 녹화는 현장에서 추가 검증해야 합니다.
샘플 시간은 기기별 카운터 기반이며, 여러 기기의 하드웨어 동시 샘플링을 보장하지 않습니다.

## 번호는 읽히는데 검색되지 않을 때

2.0.0에는 J-Link로 번호를 읽은 뒤 기기 실행을 재개하지 않는 문제가 있었습니다.
**2.0.1에서는 확인·동일 번호 저장·펌웨어 설치 후 최종 읽기가 끝나면 기기를 재시작합니다.**
구버전을 실행 중이면 앱을 완전히 종료한 뒤 다시 열고, 상단 버전이 2.1.0인지 확인하세요.

- 빠른 확인: 헤드스테이지 전원을 완전히 껐다 켠 후 **기기 검색**.
- J-Link로 읽은 ID는 유선 메모리 값입니다. 검색 목록은 실제 무선 광고 결과이며 서로 다릅니다.
- 다른 앱/동글에 이미 연결된 기기는 검색되지 않을 수 있습니다. 해당 연결을 먼저 해제하세요.
- 빈 헤드스테이지는 번호만 부여해도 광고하지 않습니다. 헤드스테이지용 펌웨어가 필요합니다.

## 연결 버튼을 눌러도 반응이 없다고 느껴질 때

별칭 입력과 동글 지정만으로는 기기를 선택한 것이 아닙니다. 해당 행의 **선택**을 눌러
파란색 **✓ 선택됨**이 표시되는지 확인하세요. 헤드스테이지 이름을 눌러도 선택할 수 있습니다.
2.0.4부터는 선택한 기기가 있을 때 연결 버튼이 활성화되고, 연결할 번호 또는 기기 수를
버튼에 표시합니다. Device Setup과 Firmware Builder는 한 기기씩, Studio는 여러 기기를 선택합니다.


## USB 동글은 꽂혀 있는데 검색이 안 될 때

한 동글은 한 CBRAIN 앱만 사용할 수 있습니다. Studio에서 연결한 상태이거나 검색 뒤 동글을
확보한 상태면 Device Setup/Builder에서 사용할 수 없습니다. 사용 중인 앱에서 **연결 해제**
또는 **종료** 후, 사용할 앱에서 **기기 검색**을 누르세요. 녹화 중이라면 녹화를 정상적으로
마친 뒤 해제하세요.

2.0.6부터 USB에서 감지한 수와 다른 앱이 사용 중인 수를 구분하고 점유 앱을 표시합니다.
예: **USB 동글 2개 · 사용 중 2개**. 이 경우 무선 검색 자체를 실행하지 못한 상태이므로
헤드스테이지가 없다고 판정한 결과가 아닙니다. 새 검색을 시작하면 이전 선택 목록을 비웁니다.
Device Setup의 작업 로그는 새 내용과 창 크기 변경 시 마지막 줄을 자동으로 표시합니다.
